# Sample files

Two small files that show how Pinfold displays images. Import them with the + button, "Open in Pinfold", or by dropping them onto the window.

| File | What it shows |
|---|---|
| `Image Sample (offline).kmz` | Everything is packed inside the KMZ, so it works without a connection: custom pin icons (`IconStyle`), row thumbnails and a photo gallery (`gx_media_links`), images, lists and a table inside descriptions, a folder description with an image, and one place without photos for comparison. |
| `Image Sample (online).kml` | Photos linked from Wikimedia Commons. Pinfold downloads them once, following the "Download Images" setting, then shows them offline. |

Images only appear when Pinfold can fetch them. Links that need a sign-in, such as the `lh3.googleusercontent.com/umsh/…` photo links in some Google My Maps exports, return "403 Forbidden" and stay empty.
